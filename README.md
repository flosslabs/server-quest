# 🚀 Server Quest (サーバークエスト)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Language: JP/EN](https://img.shields.io/badge/Language-JP%20%2F%20EN-blue.svg)](#)

**「サーバーが止まった！どうする？」を、ブラウザだけで体験・学習。** Server Questは、Linuxサーバーのトラブルシューティングをゲーム感覚で学べるオープンソースの学習プラットフォームです。



---

## 🌟 特徴

- **環境構築不要**: ブラウザを開くだけで、仮想ターミナルが即座に起動します。
- **20の実践シナリオ**: 初級のファイル操作から、上級のネットワークトラブル解決まで網羅。
- **老若男女に優しい設計**: 専門用語の解説（現場の知恵）と、直感的なUI。
- **多言語対応**: 日本語と英語をボタン一つで切り替え可能。
- **バッジシステム**: 学習の進捗を記録し、称号を授与。モチベーションを維持します。

## 🎯 ターゲット

- **初心者・学生**: Linuxコマンドを触り始めたばかりの方。
- **シニア層の再学習**: ITの仕組みをもう一度基礎から理解したい方。
- **若手エンジニア**: 実際の障害現場で使える「切り分け能力」を磨きたい方。

## 🛠 使い方 (クイックスタート)

このプロジェクトは、GitHub Pagesを利用して1分で公開できます。

1. このリポジトリを **Fork** または **Download** します。
2. GitHubリポジトリの `Settings` > `Pages` を開きます。
3. `Branch` を `main` (または `master`) に設定して保存します。
4. 発行されたURLにアクセスすれば、あなたのサーバークエストが始まります！

## 📚 シナリオ構成

| ランク | 内容 |
| :--- | :--- |
| **初級** | ファイル操作、権限変更、文字列検索 (`ls`, `chmod`, `grep`) |
| **中級** | プロセス管理、ポート確認、システム時刻 (`kill`, `ss`, `top`) |
| **上級** | ネットワーク疎通、DNS、ファイアウォール (`ping`, `nslookup`, `ufw`) |
| **超上級** | inode枯渇、メモリリーク、SSHセキュリティ、I/O負荷 |
